# Onboarding Goals
**Revision 1**
> This is NOT a set schedule. There will likely be accomodations made for midterms, PCBs taking longer than expected, etc.

**Onboarding has been designed with the following priorities:**

- Facilitating teamwork
- Lowering the barrier of entry to onboarding
- Teaching the skills required to do all basic elements
- Accelerating new members with experience to bypass onboarding
- Providing optional modules for understanding theory/non-basic things

It is recommended you come in-person to the onboarding meetings.
